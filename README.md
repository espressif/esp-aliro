# Espressif's SDK for Aliro

## Introduction

Espressif's SDK for Aliro is the official Aliro development framework for ESP32 series SoCs, which can be used to develop Aliro
Reader.

## Supported Features

Currently, Espressif's SDK for Aliro supports the following features of Aliro-over-NFC

- Standard Expedited Phase
- Fast Expedited Phase
- Reader Certificate Sending via AUTH1/LoadCert Command
- Keyslot to Look up Access Credential Public Key
- Mailbox of Exchange command
- Step-up Phase
- Reader Descriptor reporting
- Extended or Chaining APDU in NFC Transport
